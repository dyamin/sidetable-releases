# Sidetable

Downloads for Sidetable, a session cockpit for GG Network tournament players.

**Latest: [Sidetable 0.2.3 for Windows](https://github.com/dyamin/sidetable-releases/releases/download/v0.2.3-beta.1/Sidetable_0.2.3_x64-setup.exe)**

Install: run the installer. If Windows SmartScreen warns, choose More info, then Run anyway.
Sidetable then updates itself; it never restarts while your tables are open.
